# Warden Launcher

A lightweight and modern Minecraft Java Edition launcher built with Java 17 and JavaFX 17.

<!Java>

---

## ✨ Features

- **Fast & Lightweight** — Built with Java 17 and JavaFX 17, minimal resource footprint.
- **Modular Architecture** — Clean separation between UI, game logic, and account management.
- **Multiple Account Support** — Switch between Minecraft accounts seamlessly.
- **Custom Game Instances** — Manage multiple game versions and modpacks independently.
- **Modern UI** — Clean JavaFX interface with customizable themes.
- **Windows Native** — Optimized for Windows platform.

## 📦 Prerequisites

Before you begin, ensure you have the following installed:

- **JDK 17** or later (<Adoptium> recommended)
- **Maven 3.8+** (<Download>)
- **Windows 10/11** (64-bit)
