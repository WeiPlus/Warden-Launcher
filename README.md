# Warden Launcher

> A lightweight, fast, and free launcher for Minecraft: Java Edition.

---

## What Is This?

**Warden Launcher** is a free Minecraft Java Edition launcher.

It doesn't modify the game, doesn't add extra bloat — it does one thing: **helps you launch Minecraft more easily**.

If you're tired of the official launcher being slow and bloated, or you just want a clean, ad-free, completely free launcher, Warden Launcher is for you.

---

## Why Choose It?

There are already many launchers out there, but Warden Launcher has its own principles:

- **Completely free** — No paid features, no ads, no pop-ups
- **Clean interface** — Opens straight to the login screen, no flashy clutter
- **Fast startup** — The program itself is small, opens and closes quickly
- **Full-featured** — Has everything you need, nothing you don't
- **Privacy-safe** — Doesn't collect any personal information, doesn't run background processes

## Features

### Account Management

- **Premium login**: Supports Microsoft account login, can connect to official servers
- **Offline mode**: Play single-player and LAN even without a premium account
- **Multi-account switching**: Share a computer with friends? Switch accounts with one click, no repeated logins

### Version Management

- **Full version support**: Download and launch any Minecraft Java Edition release
- **Snapshot versions**: Try the latest snapshots early, experience new content first
- **Legacy versions**: Want to play an old version? No problem, download and play anytime

### Mod Support

- **One-click mod loader installation**: Forge, Fabric, NeoForge, Quilt — install with a single click
- **Drag-and-drop mod installation**: Drag downloaded `.jar` mod files directly into the launcher window for automatic installation
- **Mod conflict detection**: Helps identify mod combinations that may cause crashes

### Modpack Support

- **Import modpacks**: Supports mainstream formats like CurseForge and Modrinth
- **Export modpacks**: Share your configured game with friends
- **Modpack isolation**: Each modpack runs independently without interfering with others

### Personalization

- **Memory allocation**: Customize game memory based on your PC specs — even low-end PCs can run smoothly
- **Resolution settings**: Fullscreen, windowed, or custom resolution — your choice
- **Custom skins**: Use your favorite skin even in offline mode
- **Game directory management**: Keep multiple game saves separate without interference

## Download & Installation

### System Requirements

| Item | Requirement |
| :--- | :--- |
| **Operating System** | Windows 10 / 11 (64-bit) |
| **Processor** | Intel Core i3 or equivalent AMD |
| **Memory** | At least 4 GB |
| **Disk Space** | At least 1 GB free space |
| **Graphics** | Integrated graphics with OpenGL 2.1 support is sufficient |

> No need to install Java separately — the launcher handles it automatically.

### Installation Steps

1. Go to the **Releases** page and download the latest version
2. Double-click the downloaded `.exe` installer
3. Choose your installation location and click "Install"
4. After installation, double-click the desktop icon to launch

## How to Use

### First Time Setup

**Step 1: Choose Your Login Method**

When you open the launcher, you'll see two options:

- **Microsoft Account**: If you've purchased Minecraft Java Edition, choose this. You can connect to official servers and use premium skins.
- **Offline Mode**: Play even without a premium account — supports single-player and LAN.

**Step 2: Download a Game Version**

1. Click the "Download" button on the left
2. Select the version you want to play from the list (e.g., 1.20.4)
3. If you need mods, check Forge or Fabric at the same time
4. Click "Install" and wait for the download to finish

**Step 3: Start Playing**

1. Return to the main screen
2. Confirm your account and game version are correct
3. Click "Start Game" and wait for Minecraft to launch

### Installing Mods

**Method 1: Drag and Drop (Easiest)**

1. Select your game version in the launcher
2. Click "Mod Management"
3. Drag your downloaded `.jar` mod files from your folder into the launcher window
4. Restart the game — mods are active

**Method 2: Browse and Install**

1. Click "Mod Management" → "Browse Mods"
2. Search for the mod you want
3. Click the "Install" button
4. Restart the game

### Importing Modpacks

1. Click "Import Modpack" on the main screen
2. Select your downloaded modpack file (`.zip` or `.mrpack` format)
3. Wait for automatic download and setup to complete
4. The new game instance will appear in your version list — click to launch

### Exporting Modpacks to Share with Friends

1. Select your configured game version in the launcher
2. Click "Export Modpack"
3. Choose the export format (CurseForge or Modrinth)
4. Select what to include (mods, configs, resource packs, etc.)
5. Click "Export", save the file, and send it to your friends

## FAQ

**Q: Is the launcher free?**

A: Yes, completely free. No paid features, no ads, no hidden charges.

**Q: Do I need to buy Minecraft to use it?**

A: If you want to connect to official servers or use premium skins, you need a purchased Minecraft Java Edition account. But if you just want to play single-player or LAN, offline mode works fine — no purchase needed.

**Q: Does it support Mac or Linux?**

A: Currently only Windows 10/11 (64-bit) is supported. Mac and Linux versions are planned.

**Q: Is the launcher safe?**

A: Yes. The source code is fully open for anyone to inspect. The launcher doesn't collect your personal information, doesn't run any background processes, and doesn't modify game files (except for what's necessary to launch the game).

**Q: The launcher crashes on startup — what do I do?**

A: First, make sure you have the latest **Visual C++ Redistributable** installed — download it from the Microsoft website. If the problem persists, try uninstalling and reinstalling the launcher.

**Q: The game crashes — what do I do?**

A: Most crashes are caused by mod conflicts. Try:
1. Disable all mods and enable them one by one to find the problematic mod
2. Check the crash report in the launcher's "Logs" page to find the error cause
3. If memory is insufficient, try increasing memory allocation

**Q: Downloads are slow — what do I do?**

A: In the launcher's "Settings" → "Download", you can switch the download source. Choose a mirror closer to your location for faster speeds.

**Q: How do I update the launcher?**

A: The launcher checks for updates automatically. When a new version is available, you'll get a prompt on startup — click "Update" to download and install the latest version automatically.

**Q: Can I migrate from another launcher?**

A: Yes. In "Settings" → "Global" → "Game Directory", point the directory to the `.minecraft` folder used by your previous launcher. Your saves, mods, and configs will be preserved.

**Q: Can other players see my offline mode skin?**

A: Custom skins in offline mode are only visible to you — other players won't see them. If you want others to see your skin, you need a premium account.
